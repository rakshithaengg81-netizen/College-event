# College-event🎉

A simple college events webpage created using HTML and CSS.

## About the Project

This webpage displays information about college events such as
Rangoli Competition, Coding, Video Games, and DJ Night.

## Technologies Used

- HTML
- CSS

## Features

- Home, About, Events, and Contact sections
- Event dates and venues
- Registration links
- WhatsApp group link
- Instagram link
- Contact information
- Responsive background design

## How to Run

Open the `index.html` file in a web browser.
